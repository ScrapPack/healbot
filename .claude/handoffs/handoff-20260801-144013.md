`rig.Env` — a named requirement about the MACHINE, declared by the check that needs it:

```python
r.check("installed SKILL.md is byte-identical to the canonical copy",
        lambda: open(SKILL_INSTALLED).read() == canon, needs=MAIN_CHECKOUT)
```

When the fact is absent the row records a **declared skip** carrying the requirement's name
and reason. `Results.summary()` emits a `##ENV-SKIP##` line; `gate/tier2.py` lifts it into
`declared_skips` in the run record, prints every declaration under the verdict, and reports
the fifth lattice term `declared-skip` (`gate.py`) — exit 0, green, explicit that not
everything here was measured.

Four rules keep it from being a mute button, all asserted by `probe_rig_contract` contract 7
(11 new rows, static sweep with mutation legs in both polarities plus six runtime legs):

1. the predicate must be a **lambda** — Python evaluates arguments eagerly, so an expression
   predicate has already run, and already crashed, before the guard is entered
2. skips are **budgeted per rig** (`Results(skip_max=)`, default 0); past the budget is RED
3. a run where **nothing was measured** is RED whatever the budget allows
4. a requirement must be strictly **weaker** than the check it guards, or the guard has
   replaced the measurement
